# 元素之箭 · 七元素箭头解谜（“一箭又一箭”小游戏 Demo）

一个用 Python + pygame 实现的“一箭又一箭”风格点击解谜小游戏。
观察箭头方向与相互遮挡关系，按正确顺序点击，让所有箭头依次飞出棋盘。
界面采用原创的“七元素”配色与简练明丽的二次元画风，**全部素材均为原创生成，
未使用任何商业游戏的代码、美术素材、音效或关卡**。

---

## 一、运行方法

1. 环境：Python 3.10 及以上（开发与测试环境为 Python 3.14 + Windows）。
2. 安装依赖（二选一，二者的 `import pygame` 用法完全相同）：

   ```bash
   pip install -r requirements.txt   # pygame-ce，对新版 Python 兼容性更好
   # 或
   pip install pygame                # 官方 pygame（2.5 以上）
   ```

3. 启动游戏：

   ```bash
   python main.py
   ```

窗口大小为 540×860（竖版），鼠标操作。若音频设备不可用，游戏会自动静音，
不影响运行。

## 二、操作与规则

- 鼠标点击棋盘上的元素箭头。
- 程序沿箭头朝向，检查**同一行（左/右）或同一列（上/下）**上、箭头与棋盘
  边界之间是否还存在其他箭头（基础版口径：单格箭头，只看行列直线）。
- 前方**没有**其他箭头：箭头加速飞出棋盘并消除，播放飞出音效与金色“飞出”提示。
- 前方**存在**其他箭头：箭头留在原地，沿朝向快速晃动、变为警示红、屏幕红屏
  闪烁并提示“阻挡！”，同时**消耗一次失误次数**。
- 清空当前关卡全部箭头 → 本关通过，可进入下一关；三关全部通过显示“七元素
  试炼完成”。
- 失误次数耗尽 → 本关失败，可“重新开始”或“返回菜单”。
- 游戏界面随时可点“重新开始”把当前关卡恢复到初始状态；按 `Esc` 返回菜单。

## 三、关卡与参考通关顺序

三个关卡均由 `tools/design_levels.py` 的“逆向摆放”算法生成，再用 DFS
求解器证明存在通关顺序，并逐关人工试玩确认。坐标为 `(行, 列)`，从 0 开始，
左上角为 `(0,0)`。

- **第一关 · 风起**（5×5，6 支箭头，3 次失误）
  `(0,1)左 → (0,3)右 → (2,0)上 → (2,2)上 → (2,4)下 → (4,2)上`
- **第二关 · 溪流**（6×6，10 支箭头，3 次失误）
  `(0,5)下 → (1,2)上 → (2,0)下 → (2,1)上 → (2,3)下 → (2,4)右 → (3,2)右 → (4,1)左 → (4,2)右 → (2,2)下`
- **第三关 · 雷鸣**（7×7，14 支箭头，4 次失误）
  `(1,2)左 → (1,3)左 → (1,5)上 → (2,4)上 → (2,1)右 → (3,1)左 → (3,5)左 → (4,1)下 → (4,2)上 → (4,5)下 → (5,3)下 → (5,6)下 → (6,4)右 → (5,4)下`

通关顺序不唯一，只要每次点击当前无遮挡的箭头即可。

## 四、项目结构

```
elemental-arrows/
├─ main.py                  # 启动入口
├─ requirements.txt
├─ game/
│  ├─ settings.py           # 常量、七元素配色、动画时长
│  ├─ levels.py             # 三个关卡的数据
│  ├─ board.py              # 棋盘/箭头：路径检测、坐标换算、绘制与动画
│  ├─ ui.py                 # 字体、按钮、面板、心形失误图标
│  ├─ audio.py              # 音效加载与容错
│  └─ app.py                # 主循环、场景切换（菜单/游戏/通关/失败）
├─ assets/
│  ├─ images/bg_menu.png    # AI 文生图生成的原创开始界面背景
│  └─ sounds/*.wav          # tools/gen_sounds.py 数学波形合成的原创音效
├─ tools/
│  ├─ gen_sounds.py         # 音效合成脚本（标准库实现，可重复生成）
│  ├─ design_levels.py      # 关卡逆向生成 + DFS 求解器（开发期工具）
│  ├─ screenshot.py         # 无头渲染截图，便于无显示器环境检查界面
│  └─ make_commit.py        # 纯 Python（dulwich）的提交辅助脚本
└─ tests/
   └─ test_levels.py        # 规则与关卡测试，直接运行即可
```

## 五、测试

```bash
python tests/test_levels.py
```

覆盖：四方向路径检测与贴边边界、三关可通关性（独立参考实现与游戏代码
交叉验证）、零失误完整通关流程、失误耗尽失败、重新开始复位、被阻挡箭头
不会消失。此外进行过 60 局随机点击猴子测试，未出现异常或死局。

## 六、素材来源声明

- 开始界面背景 `bg_menu.png`：使用 AIGC 文生图工具按原创提示词生成
  （七色彩带云海、无人物无文字无 logo），未使用任何商业游戏图片。
- 音效 `click/fly/blocked/win/fail.wav`：由 `tools/gen_sounds.py` 用
  Python 标准库对正弦波、频率扫频、包络与琶音做数学合成，无第三方音频。
- 箭头宝石、面板、按钮、图标等界面元素：全部由 pygame 代码绘制
  （见 `board.py` / `ui.py`）。
- 关卡数据：算法生成 + 求解器验证 + 人工挑选，非商业游戏关卡。

## 九、后续可扩展方向（给后续修改留空间）
