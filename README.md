# 元素之箭 · 七元素箭头解谜（“一箭又一箭”小游戏）

一个用 Python + pygame 实现的“一箭又一箭”风格点击解谜小游戏。
观察箭头方向与相互遮挡关系，按正确顺序点击，让所有箭头依次飞出棋盘。
界面采用原创的“七元素”配色、赛璐璐风精灵向导与明丽的二次元画风，
**全部素材均为原创生成，未使用任何商业游戏的代码、美术素材、音效或关卡**。

---

## 一、运行方法

1. 环境：Python 3.10 及以上（开发与测试环境为 Python 3.12 + Windows）。
2. 安装依赖（二选一，二者的 `import pygame` 用法完全相同）：

   ```bash
   pip install -r requirements.txt   # pygame-ce，对新版 Python 兼容性更好
   # 或
   pip install pygame                # 官方 pygame（2.5 以上）
   ```

3. 启动游戏：

   ```bash
   python main.py
   ```

窗口大小为 540×860（竖版），鼠标操作。若音频设备不可用，游戏会自动静音，
不影响运行。

## 二、操作与规则

- 鼠标点击棋盘上的元素箭头。
- 程序沿箭头朝向，检查**同一行（左/右）或同一列（上/下）**上、箭头与棋盘
  边界之间是否还存在其他箭头（基础版口径：单格箭头，只看行列直线）。
- 前方**没有**其他箭头：箭头加速飞出棋盘并消除，播放飞出音效与星光爆发。
- 前方**存在**其他箭头：箭头留在原地晃动警示、屏幕红闪并提示“阻挡！”，
  同时**消耗一次失误次数**。
- 清空当前关卡全部箭头 → 本关通过并按失误次数评星（零失误三星、失误一次
  两星、其余一星），可进入下一关；六个关卡全部通过显示“七元素试炼完成”。
- 失误次数耗尽 → 本关失败，可“重新开始”或“返回菜单”。

## 三、功能一览

- **六个手工关卡**：5×5 到 8×8、6～22 支箭头，全部经 DFS 求解器验证可通关；
  在 `game/levels.py` 中直接追加关卡 dict 即可扩关。
- **随机关卡 · 元素幻境**：逆向摆放算法即时生成 7×7、15 支箭的全新棋盘，
  生成即可通关，可无限“再来一局”。
- **提示**：调用 `Board.removable_arrows()` 高亮当前所有可飞出的箭头。
- **计时与步数**：HUD 实时显示用时、步数、剩余箭头与失误心形。
- **撤销**：逐步回退成功飞出的操作（棋盘、步数、失误数一并恢复）。
- **星级评价与本地存档**：`save.json` 记录每关最高星级、最佳用时与解锁进度。
- **选关界面**：关卡卡片显示星级/最佳成绩，未解锁关卡带锁。
- **自动演示**：DFS 求出通关顺序后由精灵逐支飞出，可中途停止。
- **奇幻表现**：原创白色小精灵向导「灵灵」（圆身体、小翅膀、四角星天线，
  有开心/惊讶/沮丧/庆祝等表情与对话气泡）、七色环境光点、飞出星光、
  碰撞火星、通关彩屑、渐变背景。

## 五、自动化测试

```bash
# Windows PowerShell 无头运行（不弹窗、不发声）
$env:SDL_VIDEODRIVER="dummy"; $env:SDL_AUDIODRIVER="dummy"
python -m unittest tests.test_acceptance -v

# 基础规则与关卡测试
python tests/test_levels.py
```

`tests/test_acceptance.py` 共 13 个用例，全部通过：

- **T01** 点击无阻挡箭头 → 飞出棋盘并消失；
- **T02** 点击有阻挡箭头 → 不消失且失误次数减 1；
- **T03** 边缘箭头飞出棋盘 → 正常消失、无越界错误（六关逐帧校验）；
- **T04** 清空全部箭头 → 显示通关并进入下一关；
- **T05** 失误耗尽 → 显示失败并允许重新开始；
- **T06** 游戏中重开 → 箭头布局与失误次数恢复；
- **T07–T13** 提示、撤销、计时步数、随机关卡、自动演示、星级存档、
  选关锁定。

详细测试过程与结果见 [`测试报告.md`](测试报告.md)。

## 六、素材来源声明

- 开始/选关背景 `bg_menu.png`：使用 AIGC 文生图工具按原创提示词生成
  （七色彩带云海、无人物无文字无 logo），未使用任何商业游戏图片。
- 音效 `click/fly/blocked/win/fail.wav`：由 `tools/gen_sounds.py` 用
  Python 标准库对正弦波、频率扫频、包络与琶音做数学合成，无第三方音频。
- 精灵向导、箭头宝石、粒子、面板、按钮、图标等：全部由 pygame 代码绘制
  （见 `mascot.py` / `fx.py` / `board.py` / `ui.py`），精灵形象为原创设计。
- 关卡数据：算法生成 + 求解器验证 + 人工挑选，非商业游戏关卡。
